# Продуктовый бриф: PawnMarket — Маркетплейс ломбардов

## Резюме

**PawnMarket** — специализированный маркетплейс, где ломбарды выставляют нереализованные залоговые товары, а покупатели приобретают их через единую платформу с проверенной информацией о каждом предмете. Площадка выступает посредником, обеспечивая прозрачность, доверие и удобство для обеих сторон.

Рынок ломбардов в России превышает **300 млрд ₽** в год, 94% залогов — золотые изделия, которые формируют стабильный товарный поток. При этом специализированного маркетплейса для ломбардов не существует — они вынуждены продавать через Авито как обычные продавцы, без инструментов для массовой выгрузки, проверки подлинности и управления заказами.

«Биография вещи» — проверенная история каждого товара с экспертизой, таймлайном и рейтингом прозрачности — становится главным конкурентным преимуществом платформы, решая ключевую проблему вторичного рынка: отсутствие доверия.

## Проблема

**Покупатели** не доверяют товарам из ломбардов. На Авито и Юле нет гарантий подлинности, нет стандартизированной оценки состояния, нет защиты покупателя. Человек, желающий купить золотое кольцо или часы со скидкой, вынужден ехать в ломбард лично, рискуя получить подделку или краденое.

**Ломбарды** хотят продавать онлайн, но не имеют инструментов. Каждый товар уникален, выгрузка на Авито — ручная работа, фотографируй и описывай каждую единицу. Нет интеграции с учётными системами, нет аналитики спроса, нет единого канала сбыта. Результат — нереализованный товар лежит на витрине месяцами.

## Решение

Веб-приложение — маркетплейс с двумя основными интерфейсами:

1. **Витрина для покупателей** — каталог товаров с поиском, фильтрами по категориям (ювелирные изделия, техника, часы), карточка товара с «биографией»: рейтинг прозрачности, таймлайн жизни вещи, экспертиза подлинности, проверка по базам. Оформление заказа с выбором доставки или самовывоза.

2. **Кабинет для ломбардов** — регистрация, добавление товаров, управление заказами, просмотр аналитики продаж.

Платформа берёт **1% комиссию** с каждой сделки.

## Что делает нас другими

- **Первый специализированный маркетплейс для ломбардов в России.** Ниша пустая — Авито не решает специфику ломбардов.
- **«Биография вещи»** — ни одна площадка не предлагает проверенную историю каждого товара с рейтингом прозрачности. Это меняет восприятие покупки с рук на покупку с гарантией.
- **Низкая комиссия** — 1% против隐性 расходов на ручное управление продажами через Авито.

## Кому это нужно

**Покупатели** — люди, которые хотят купить ювелирные изделия, электронику, часы и другие товары со значительной скидкой, но с гарантией прозрачности и подлинности. Возраст не ограничен.

**Ломбарды** — российские ломбарды, которым нужен эффективный онлайн-канал сбыта для нереализованных залоговых товаров. Консервативны, нуждаются в простом инструментарии.

## Критерии успеха

- **10+ ломбардов** зарегистрированы в первые 3 месяца
- **500+ товаров** в каталоге через 3 месяца
- **50+ оформленных заказов** в месяц к концу 3-го месяца
- Средний рейтинг прозрачности товаров **≥ 70/100**
- NPS покупателей **≥ 40**

## Область видимости (MVP)

**Включено:**
- Каталог товаров с поиском и фильтрами по категориям
- Карточка товара с «биографией» (рейтинг прозрачности, история, фото)
- Регистрация и кабинет ломбарда (добавление товаров, управление заказами)
- Корзина и оформление заказа (самовывоз + доставка)
- Моковые данные на бэкенде (React, TanStack React Query)

**Исключено (после MVP):**
- Платная экспертиза подлинности через партнёров
- Премиум-подписка для покупателей (ранний доступ к лотам)
- Лист ожидания / запросы покупателей
- Интеграция с 1С и учётными системами ломбардов
- Аналитика продаж для ломбардов
- Эксклюзивность по территории
- Проверка серийных номеров через базы МВД

## Видение

Если PawnMarket успешно запустится, через 2–3 года это станет **основным онлайн-каналом сбыта для ломбардов в России**. Платформа эволюционирует из каталога в полноценную экосистему: платная верификация товаров, интеграция с учётными системами, аналитика рынка, мобильное приложение. Ломбарды зависят от PawnMarket как от основного канала продаж, а покупатели приходят сюда первым делом, когда ищут выгодную покупку с гарантией.
