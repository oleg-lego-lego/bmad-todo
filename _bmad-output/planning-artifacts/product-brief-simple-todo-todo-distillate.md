# Детализация: PawnMarket — Маркетплейс ломбардов

## Технический контекст

- **Фронтенд:** React + TanStack React Query
- **Бэкенд (MVP):** моковые данные, реальный бэкенд отложен
- **Платформа:** веб-приложение (мобильное приложение — пост-MVP)
- **Дизайн:** отсутствует, требует отдельного обсуждения (UX-дизайн — следующий этап BMad)

## Ключевая идея: «Биография вещи»

- **Рейтинг прозрачности** — шкала 0–100: пройдена ли экспертиза, есть ли фото оригинального чека, проверен ли серийный номер, не в розыске ли
- **Таймлайн жизни вещи** — горизонтальная лента: производство → покупка → залог → оценка ломбарда → выставление на площадке
- **Проверка через базы данных (пост-MVP)** — серийные номера через МВД (угон/краденое), Apple/Samsung (activation lock), IMEI
- **В MVP:** категория, состояние (оценка ломбарда), фото, цена залога, описание — максимум информации от ломбарда без внешней верификации

## Монетизация

- **Комиссия 1%** с каждой сделки — текущая модель
- **Платная экспертиза подлинности (пост-MVP)** — подключение партнёров-оценщиков, бейдж «Проверено PawnMarket»
- **Премиум-подписка для покупателей (пост-MVP)** — ранний доступ к лотам за 24 часа, уведомления о поступлении конкретных товаров (FOMO-модель)
- **Риски комиссии 1%:** платежные процессоры берут ~3%, что может сделать модель убыточной — вопрос требует проработки

## Стратегия привлечения ломбардов (из мозгового штурма)

- **Нулевая комиссия первые 30 дней** — снятие барьера входа, ломбарды консервативны
- **Личный менеджер / виртуальный помощник** — помощь с загрузкой первых 50 товаров, настройка фото, описания
- **Интеграция с 1С (пост-MVP)** — автоматическая выгрузка товаров, ломбард ведёт учётку как обычно
- **Аналитика продаж (пост-MVP)** — какие товары быстрее продаются, оптимальные цены, тренды
- **Эксклюзивность территории (пост-MVP)** — в одном районе только один ломбард-партнёр

## Спрос: лист ожидания (пост-MVP)

- Покупатель ставит запрос: «Ищу золотое кольцо 585, 3–5 грамм, до 15 000 ₽»
- Ломбарды получают заявку и предлагают варианты
- Обратный маркетплейс — покупатель формирует спрос, ломбарды конкурируют за сделку

## Конкурентный ландшафт

- **Авито / Юла** — доминируют, но ломбарды как обычные продавцы, без специализированных функций (нет гарантий, нет массовой выгрузки, нет верификации)
- **Mosgorlombard** — крупнейшая сеть ломбардов РФ, разрабатывает собственную resale-платформу (один продавец, не маркетплейс)
- **Комиссионки.ру** — ближайший аналог, но для комиссионных товаров, не для ломбардов
- **ResaleMarket.ru** — комиссионный онлайн-магазин электроники, ограниченный охват (Москва, Казань, Нижний Новгород)
- **Белое пространство:** нет единого маркетплейса, агрегирующего несколько ломбардов с унифицированной верификацией и стандартизированными листингами

## Рыночные данные

- Займы ломбардов РФ: 302 млрд ₽ (2024), 190 млрд ₽ за H1 2025 (ускорение)
- Прибыль ломбардов РФ: 8.8 млрд ₽ (+73% к предыдущему году)
- 94% залогов — золотые изделия
- Нишевые маркетплейсы РФ: 990 млрд ₽ (+22% к предыдущему году)
- Онлайн-аудитория РФ: 133+ млн пользователей
- Глобальный рынок ломбардов: ~$39.9 млрд (2024), прогноз $50.7 млрд к 2031

## Ключевые проблемы (из исследования)

**Ломбарды:**
- Верификация подлинности в масштабе — сложна и ошибочна для люксовых часов, дизайнерских товаров, ювелирных изделий
- Платёжные процессоры классифицируют ломбарды как high-risk
- Каждый товар уникален — управление листингами трудоёмко без инструментов массовой выгрузки
- Дефект доверия — покупатели не доверяют без документации происхождения

**Покупатели:**
- Нет механизма возврата / жалоб на Авито
- Неопределённость состояния и подлинности без личного осмотра
- Фрагментированное предложение — поиск по нескольким сайтам ломбардов или визиты лично

## Открытые вопросы

1. Как работает «биография вещи» в MVP без внешней верификации — какие данные обязательны от ломбарда?
2. Стратегия запуска: нулевая комиссия на старте — на какой срок? Переход на 1% когда?
3. Устойчивость модели 1% с учётом стоимости платёжной обработки (~3%)
4. Логистика доставки: кто несёт ответственность за страховку ювелирных изделий?
5. Юридические аспекты перепродажи залогового имущества ломбардами — региональные различия в законодательстве РФ
6. Решение проблемы «курицы и яйца» — конкретный план привлечения первых ломбардов и покупателей

## Сигналы области видимости

**В MVP:**
- Каталог товаров с поиском и фильтрами по категориям
- Карточка товара с базовой «биографией»
- Регистрация и кабинет ломбарда
- Корзина и оформление заказа (самовывоз + доставка)

**Пост-MVP (подтверждено):**
- Платная экспертиза подлинности
- Премиум-подписка для покупателей
- Лист ожидания / запросы покупателей
- Интеграция с 1С
- Аналитика продаж для ломбардов
- Эксклюзивность территории

**Отклонённые идеи:**
- Нет отклонённых — все идеи из штурма отложены в пост-MVP, ни одна не была отвергнута

## Лучшие практики маркетплейсов (из исследования)

- **Доверие — дифференциатор #1** для платформ б/у товаров: бейджи верифицированных продавцов, гарантии подлинности, стандартизированная шкала состояния
- **Просмотр без регистрации** — создавай аккаунт только при оформлении заказа
- **Фактор срочности** — каждый б/у товар действительно уникален, используй это естественно
- **Специфичные фильтры по категориям** — караты для ювелирных изделий, модель/год для часов, характеристики для электроники
- **Инструменты массовой загрузки** для продавцов — необходимы для ломбардов с сотнями товаров
- **Интегрированная логистика** с застрахованной доставкой для ценных товаров
- **Стандартизированные политики разрешения споров и возвратов**
